# DVD Bouncing Logo Screensaver — The Office Edition

Классический скринсейвер с прыгающим логотипом DVD, как в сериале **«Офис» (The Office)** — тот самый момент, когда сотрудники офиса Dunder Mifflin заворожённо смотрят на экран и ждут, когда квадратик попадёт точно в угол.

Реализация написана на C# (WinForms, .NET Framework 4.x), собирается штатным `csc.exe` — **Visual Studio и .NET SDK не нужны**.

## Что внутри

```
office_screensaver/
├── src/
│   └── Program.cs            # исходник скринсейвера
├── bin/
│   └── DvdScreensaver.exe    # собранный бинарник (создаётся build.bat)
├── build.bat                 # сборка
├── preview.bat               # запустить полноэкранно на всех мониторах
├── test-windowed.bat         # запустить в обычном окне (самый простой тест)
├── install.bat               # установить как системный скринсейвер (требует админа)
├── uninstall.bat             # удалить
├── smoke-test.ps1            # автотест: запустить и убить процесс
├── kill-dvd.ps1              # снять зависший процесс (если preview.bat что-то заблокировал)
└── check-owner.ps1           # посмотреть, от чьего имени висит процесс
```

## Возможности

- **Полноэкранный режим на каждом мониторе** — мульти-монитор работает.
- **Оконный режим для теста** (`/w`) — обычное ресайзиble-окно, удобно для проверки.
- **Диалог настроек** (кнопка «Параметры…» в «Параметры заставки»):
  - **Speed** — множитель скорости логотипа (0.5× – 3.0×).
  - **Logo size** — доля высоты экрана (5% – 30%).
  - **Show hit counter** — показывать ли счётчик «hits / corner hits» в углу.
  - **Corner text** — что писать при попадании в угол (по умолчанию `CORNER!`, можно поставить своё).
  - Настройки сохраняются в `HKCU\Software\TheOfficeScreensaver`.
- Физика отскока: угол падения равен углу отражения — логотип дрейфует к углам естественно.
- Цвет меняется при каждом ударе о стену (никогда не повторяется дважды подряд).
- Обнаружение попадания в угол: когда логотип касается двух стен одновременно, на экране вспыхивает надпись **«CORNER!»** (или ваш текст) и счётчик corner hits увеличивается.
- Скрытие системного курсора на время работы.
- Выход: клик мыши, любая клавиша или движение мыши дальше 12 пикселей от точки старта (порог сделан специально, чтобы не словить ложный выход от дрожания тачпада/мыши в первые миллисекунды показа).
- Поддержка Per-Monitor DPI v2 — на 4K-мониторах логотип не растягивается.

## Сборка

Двойной клик по `build.bat`. Если сборка прошла успешно, появится файл `bin\DvdScreensaver.exe`.

Под капотом вызывается:
```
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe
   /target:winexe /platform:anycpu /optimize+
   /out:bin\DvdScreensaver.exe
   src\Program.cs
```

Никаких сторонних зависимостей — только стандартные `System.dll`, `System.Drawing.dll`, `System.Windows.Forms.dll` из .NET Framework, который есть в любой Windows 11.

## Быстрый тест без установки

**Лучший способ для проверки** — `test-windowed.bat`: открывает обычное окно 820×620 с заголовком «DVD Screensaver — test mode». Видно сразу, никаких неожиданностей. Закрытие — клик или любая клавиша.

`preview.bat` — то же самое, но во весь экран на всех мониторах. Двигайте мышь или нажмите что-нибудь, чтобы выйти.

## Установка как системного скринсейвера (Windows 11)

1. Соберите проект (`build.bat`).
2. **Правой кнопкой мыши по `install.bat` → «Запуск от имени администратора».** Это нужно, потому что файл копируется в `C:\Windows\System32`, откуда Windows подхватывает список скринсейверов для панели «Параметры персонализации».
3. Откройте **Пуск → Параметры → Персонализация → Экран блокировки → Параметры заставки**.
4. В выпадающем списке «Заставка» выберите **«DVD Bouncing Logo (The Office Edition)»**.
5. Нажмите «Предпросмотр», чтобы убедиться, что всё работает.
6. Задайте время до включения (по умолчанию скрипт ставит 5 минут) и поставьте галочку «Начинать с экрана входа в систему», если хотите.

Готово. Теперь, оставив компьютер в покое на выбранное время, вы увидите тот самый прыгающий DVD-логотип, а попадание в угол будет сопровождаться короткой вспышкой и надписью «CORNER!».

## Удаление

Правой кнопкой по `uninstall.bat` → «Запуск от имени администратора». Скрипт удалит `.scr` из System32 и вернёт предыдущие настройки заставки.

## Как это работает (коротко)

- `Program.Main` разбирает классические аргументы скринсейвера Windows: `/s` — полный экран, `/p <hwnd>` — превью в панели настроек, `/c` — окно конфигурации.
- На каждый монитор создаётся свой экземпляр `ScreensaverForm`, который занимает весь экран этого монитора (`Bounds = Screen.Bounds`) и рисуется поверх всех окон.
- На каждом тике таймера (60 FPS) обновляется позиция логотипа, проверяются столкновения со стенами и углами. При ударе о стену меняется направление только той оси, в которую упёрся логотип — это и есть «угол падения = угол отражения», благодаря которому логотип в конце концов стремится к углу экрана.
- При попадании в угол включается переменная `cornerFlash`, которая за 1.5 секунды затухает — её использует `OnPaint` для отрисовки вспышки и надписи «CORNER!».

## Если что-то пошло не так

- **`build.bat` пишет "the process cannot access the file ... it is being used by another process".** Где-то уже висит запущенный экземпляр `DvdScreensaver.exe`. Запустите `kill-dvd.ps1` (PowerShell-скрипт в комплекте) — он прибьёт все такие процессы через WMI Terminate, который работает там, где обычный `Stop-Process` упирается в «Access denied». После этого билд пройдёт.
- **`install.bat` или `uninstall.bat` не может удалить/перезаписать `DvdScreensaver.scr` даже от админа (`Access is denied`).** Скорее всего файл держит **Windows Search Indexer** (`SearchProtocolHost.exe`) или антивирус, открывшие его с `FILE_SHARE_NONE` на время сканирования. Три способа разрулить:
  1. **Подождать 10-15 секунд** и повторить — Indexer обычно быстро отпускает handle.
  2. **Поставить Search на паузу** на время установки: `net pause "Windows Search"` (от админа), затем `net continue "Windows Search"`.
  3. **Запустить `force-remove.bat`** (от админа) — он делает `takeown` + `icacls /reset` + rename + delete, а если не вышло — планирует удаление через `PendingFileRenameOperations` (сработает после перезагрузки).
- **Скрипт `uninstall.bat` показывает «still there» в логе.** Это значит, что какой-то сервис держит файл. Откройте `uninstall.log` — там будет PowerShell-вывод `Get-CimInstance Win32_Process`, который показывает, какой процесс держит handle. Типичные виновники: `SearchProtocolHost.exe`, `MsMpEng.exe`, `TiWorker.exe`.
- **Запуск из Git Bash даёт `RM: cannot remove 'Run'...`.** Это значит, что bash пытается интерпретировать `.bat`-файл как shell-скрипт. Запускайте из PowerShell/cmd: `.\install.bat`, или просто двойным кликом из проводника. (Мы уже убрали ту странную строку, из-за которой это происходило — старые `install.bat` могли иметь эту проблему.)
- **`preview.bat` вроде бы ничего не делает.** Скорее всего процесс запустился, но вы смотрите не на тот монитор (на нескольких мониторах скринсейвер занимает каждый по отдельности — посмотрите на все). Для проверки сначала запустите `test-windowed.bat` — он откроет обычное окно 820×620, которое сразу видно.
- **После выхода из скринсейвера показывается серый экран, а не экран блокировки.** Это значит, Windows не дождалась завершения процесса скринсейвера. Должно быть исправлено в новых версиях через `Environment.Exit(0)` в `ExitFast()` — обновитесь через `install.bat`.
- **Скринсейвер закрывается через секунду после запуска без видимой причины.** Так бывает, если в системе что-то постоянно дёргает курсор меньше чем на 12 пикселей (тачпад, левая кнопка глючит и т.п.). Порог в 12 px задан в `MouseSlackPx` в `src/Program.cs`, можно увеличить.
- **Не появляется в списке заставок.** Убедитесь, что `install.bat` запущен от имени администратора и что файл `C:\Windows\System32\DvdScreensaver.scr` существует.
- **Двойной монитор: заставка только на одном.** Проверьте, что в «Параметры заставки» не стоит «Только экран 1». Скринсейвер поддерживает все мониторы.
- **Курсор мыши не пропадает.** Это лечится движением мыши или нажатием клавиши — заставка закроется.
- **Антивирус ругается на `.scr`.** `.scr` для Windows — это обычный исполняемый файл (PE), что и вызывает эвристику. Исходник открытый (`src/Program.cs`), при желании можно собрать самому.

Приятного ожидания угла. 🎯
